Publicar no GitHub Pages

Siga os 6 passos abaixo — leva menos de 10 minutos. Gratuito e automático.

1

Criar conta no GitHub

Acesse github.com → clique em Sign up

Use o e-mail soshidraulica31@gmail.com e escolha o usuário soshidraulica

2

Criar o repositório

Após entrar, clique em + New repository e preencha:

Repository name: site
Visibility: ✅ Public
✅ Add a README file

Clique em Create repository

3

Fazer upload dos arquivos

Dentro do repositório clique em Add file → Upload files

Arraste todos os arquivos desta pasta sos-hidraulica-site:

📄 index.html  ← site completo
📄 CNAME       ← domínio personalizado
📄 README.md
📁 .github/workflows/deploy.yml  ← deploy automático

Clique em Commit changes

⚠️ A pasta .github começa com ponto — certifique-se de incluí-la no upload.
4

Ativar o GitHub Pages

No repositório clique em Settings → menu lateral Pages

Em Source selecione GitHub Actions e salve.

Em ~2 minutos o site estará disponível em:

https://soshidraulica.github.io/site
5

Registrar domínio soshidraulica.com.br

Acesse registro.br → pesquise soshidraulica.com.br → registre (R$ 40/ano)

No painel DNS do registro.br adicione estas entradas:

TipoNomeValor
A@185.199.108.153
A@185.199.109.153
A@185.199.110.153
A@185.199.111.153
CNAMEwwwsoshidraulica.github.io
⏱ Propagação DNS leva de 15 min a 24h — é normal!
6

Vincular domínio no GitHub

Volte em Settings → Pages no GitHub

Em Custom domain digite: www.soshidraulica.com.br

Marque ✅ Enforce HTTPS — cadeado de segurança gratuito ativado!

Site no ar!

Após estes passos seu site estará em www.soshidraulica.com.br
com HTTPS gratuito, deploy automático e domínio próprio.
